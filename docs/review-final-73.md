# ANDREA — relatório das 73 conferências individuais

Conferência documental concluída para os 73 protocolos distintos, incluindo os que haviam recebido ajustes focais anteriormente. Cada revisão integral foi confrontada com o PDF municipal original, com registro de problemas/correções e testes dos caminhos. Nenhum protocolo foi creditado apenas por passar em teste estrutural.

Todos os 25 lotes tiveram commit enviado, GitHub Actions concluído com sucesso e comparação dos arquivos publicados no GitHub Pages. As provas específicas de publicação estão nos relatórios dos lotes. Os dados deste relatório registram o estado após a confirmação do lote 25.

**Situação clínica:** 72 protocolos têm pendências documentais/clínicas explicitadas; 1 não tem pendência específica registrada (oncologia). Isto não representa aprovação clínica dos 73 protocolos nem permite considerar resolvidas as lacunas municipais. Não foram inventados tratamentos ou destinos para encobrir informação ausente. Nas telas, esses pontos permanecem identificados para validação.

[Aplicação publicada](https://jeffelder.github.io/GeradorFluxosConduta/) · [Registro estruturado](review-register.json) · [Versão JSON deste relatório](review-final-73.json)

## Contagem e método

24 lotes × 3 protocolos = 72. O lote 25 reuniu SIM-P (último protocolo inédito), farmacodermias e febre (duas reconferências integrais). Portanto: 73 IDs únicos, 75 conferências, sem contar os repetidos duas vezes. Cada lote começou somente após sucesso e verificação dos arquivos publicados do anterior.

As versões históricas municipais e seus hashes SHA256 estão no registro e nos relatórios. Os testes executam navegação do aplicativo por eventos reais em adaptador DOM, seleções/voltar e as combinações dos escores descritas em cada lote. Não são ensaios clínicos. A conferência visual foi dos PDFs; comparação de publicação usa conteúdo HTTP byte a byte e version.json.
